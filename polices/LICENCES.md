# Polices pour les cartes de partage

Fichiers TrueType variables, tels que distribués sur github.com/google/fonts — utilisés
uniquement côté serveur pour dessiner les images d'aperçu (`carte.go`), jamais servis.

- **Newsreader** (Production Type) — SIL Open Font License 1.1
- **Instrument Sans** (Rodrigo Fuenzalida, Jordan Egstad) — SIL Open Font License 1.1
