# DECISIONS

Une ligne datée par choix. Contexte complet : document projet dans le wiki.

- 2026-08-27 — Nom : **Perches**. Vocabulaire : liste, intention, perche (le lien partagé), hôte, invité, état, croisement.
- 2026-08-27 — Construction neuve, pas un fork de Gathio ; on reprend ses choix éprouvés (lien secret d'édition, accès par lien, effacement automatique, pas d'OAuth).
- 2026-08-27 — Langage : **Go** — binaire unique, rendu côté serveur, SQLite, un conteneur, presque pas de JavaScript.
- 2026-08-27 — Licence : **AGPL-3.0**.
- 2026-08-27 — Pas d'étape Gathio : le premier usage est un statement, l'outil fait partie du message. v0 bornée à un week-end.
- 2026-08-27 — Capacité indicative, jamais bloquante : aucun bouton ne se grise, les invités se régulent d'eux-mêmes.
- 2026-08-27 — Notifications : logistique seulement (annulation, date, lieu), jamais social. Canal unique = l'e-mail optionnel du rappel ; sans e-mail, l'invité revérifie la page.
- 2026-08-27 — Carte Open Graph toujours complète, y compris pour les intentions « lien seulement » : une perche tendue est visible de quiconque tient le lien.
- 2026-08-27 — L'effacement concerne la page publique ; l'hôte garde une archive privée complète (prénoms et mots compris, comme des lettres reçues).
- 2026-08-27 — Lien secret perdu sans e-mail de récupération : liste orpheline, assumé — elle se vide d'elle-même à mesure que ses intentions passent.
- 2026-08-27 — Une liste par personne ; la visibilité « lien seulement » par intention remplace les listes multiples.
- 2026-08-27 — L'hôte peut effacer une réponse ; rate limiting minimal sur les formulaires sans compte.
- 2026-08-27 — Instance de Gilles : création de listes sur code d'invitation.
- 2026-08-27 — Vocabulaire du domaine en français jusque dans le schéma SQL (listes, intentions, reponses) : le vocabulaire fait partie du produit.
- 2026-08-27 — Contraintes CHECK comme première ligne des conventions : le statut « non » et l'intention sans borne (ni date ni échéance) sont impossibles en base, pas seulement dans l'interface.
- 2026-08-27 — v0 : stdlib `net/http` (routes Go 1.22+), `modernc.org/sqlite` (pur Go, sans cgo), templates et schéma embarqués dans le binaire, zéro JavaScript, zéro cookie.
- 2026-08-27 — Identité de l'invité : rien — pas même un cookie. Répondre est un POST anonyme portant un prénom.
- 2026-08-27 — Rappels de la veille : boucle horaire in-process, idempotente via le journal `envois`. Pas de cron externe.
- 2026-08-27 — Effacement public des réponses : 30 jours après la date de l'intention. La v0 exige une date (« à fixer » viendra avec la variante ouverte).
- 2026-08-28 — L'invitation n'existe pas dans l'interface : un lien `/?code=…` sorti de la CLI ouvre le formulaire, et l'accueil sans code ne parle ni de création ni d'invitation. Un ami qui tombe sur l'accueil n'a rien à y faire.
- 2026-08-28 — Ouvrir une liste = trois champs (titre, adresse, e-mail) puis l'atelier directement : la lettre s'écrit là où elle se relit. Pas de page intermédiaire ; la clé d'édition est l'adresse de l'atelier.
- 2026-08-28 — Partager = copier un lien, rien d'autre. Chaque page et chaque perche a son lien copiable dans l'atelier. Une seule touche de JavaScript, en amélioration progressive : le bouton « copier ».
- 2026-08-28 — Vocabulaire à l'écran : « atelier » pour la page d'édition, « clé » pour le lien secret, « perche tendue » pour une intention à venir. Le formulaire d'une perche montre quatre champs ; le reste sous « Plus d'options ».
- 2026-08-28 — Le « silence vaut pas cette fois » reste une convention du système, pas un slogan : une mention douce sur la page de réponse, rien en pied de page ni à l'accueil.
- 2026-08-28 — « État » reste le mot du domaine (schéma, README) ; à l'écran il devient « En ce moment », pour ne pas sonner comme un diagnostic.
- 2026-08-28 — Troisième réponse « ah zut, j'aurais bien aimé », à part entière et visible comme les autres : elle dit l'envie, pas l'absence. Le « non » reste impossible. Pas de rappel de la veille pour qui ne vient pas.
- 2026-08-28 — Anti-nuisance sans friction : pot de miel sur le formulaire de réponse, `noindex` sur toutes les pages (on n'y arrive que par un lien), limite de débit par IP. Rien qui demande quoi que ce soit à un humain.
- 2026-08-28 — Pas de login. Le navigateur de l'hôte retient son atelier (cookie HttpOnly, un an, posé uniquement en visitant `/e/…`) : taper l'adresse du site ramène à l'atelier. « Zéro cookie » reste vrai pour l'invité. Le lien secret par e-mail reste la clé de secours (SMTP Gmail de l'instance).
- 2026-08-28 — L'adresse de la page se dérive du titre (« Les perches de Léa » → `/l/lea`), dédoublonnée par suffixe ; on ne la demande pas, on ne la modifie pas — c'est le lien que les amis ont reçu.
- 2026-08-28 — L'accueil dépend d'où l'on arrive : navigateur qui connaît l'atelier → le lien ; hôte sans cookie → « ton e-mail, on t'envoie ton atelier » ; nouveau venu → « sur invitation de quelqu'un qui a sa liste ». L'e-mail devient obligatoire à l'ouverture : c'est la seule façon de retrouver l'atelier, et le lien magique remplace le login.
- 2026-08-28 — L'invitation revient dans l'atelier, mais tout en bas, repliée, et nommée pour ce qu'elle est : « Un ami veut sa propre liste ? » — explicitement distincte du partage.
- 2026-08-28 — Revue complète du parcours : l'accueil redirige droit vers l'atelier quand le navigateur le connaît ; l'e-mail ne se redemande jamais (affiché en pied d'atelier, modifiable dans « Réglages » avec le titre et l'adresse) ; l'aperçu de l'adresse est vivant pendant la frappe (JS miroir de `slugDe`, le serveur reste l'autorité) ; les autres listes du même e-mail sont listées.
- 2026-08-28 — Retiré le jour même : « Tes autres listes » (revue sécurité). L'e-mail n'est jamais vérifié ; l'afficher comme clé vers d'autres ateliers donnerait accès à la liste de quiconque en déclarant l'adresse. Le seul canal vérifié reste le courriel de récupération.
- 2026-08-28 — Tout se corrige : une perche se modifie entièrement (quoi, quand, où, mots, options) ; seuls un changement de date ou de lieu valent un mot aux invités. À l'écran, la « lettre » devient « introduction » (le mot du domaine reste `lettre` en base).
- 2026-08-28 — Lot 1 de la revue red team (robustesse) : corps de requête borné à 64 Ko et champs bornés côté serveur ; limiteur sur toutes les écritures de l'atelier ; un e-mail par perche, 200 réponses par perche au plus ; courriels envoyés hors de la requête ; codes d'invitation à 64 bits, expirés après 30 jours, consommés dans la transaction qui crée la liste ; X-Forwarded-For cru seulement si `PERCHES_DERRIERE_PROXY` ; URL externe http(s) seulement ; en-têtes de sécurité et CSP par empreinte du seul script.
- 2026-08-28 — Décisions après la revue red team (Gilles) : « ah zut, j'aurais bien aimé » rendu en phrase, en dernier (« Anna aurait bien aimé. ») ; l'option « à confirmer » disparaît — l'hôte y va de toute façon, sans exception ; une réponse par prénom et par perche, redonner son prénom remplace ; plus de champ « état » — l'introduction porte la voix de l'hôte et accompagne chaque perche (convention 6 reformulée) ; les e-mails des invités sont effacés un mois après la date et absents de l'export ; l'accueil suggère aussi un titre sans le mot « perches ».
- 2026-08-28 — Lot 2 (le partage et la perche) : carte de partage complète (première vraie phrase, image, favicon, site_name), JSON hors de la page publique (lien alternatif), dates relatives (« demain », « dans 4 jours »), date en encre, réponses tactiles + repli « un mot, un rappel ? », redirection après réponse, perche annulée/passée sans promesse et ICS `STATUS:CANCELLED`, rappels entre 8 h et 20 h, présences avec les personnes discrètes et les places.
- 2026-08-28 — Lot 3 (l'atelier et les textes) : toute erreur est une page du site avec un retour ; 404 en français, liens abîmés réparés (point final, slash, majuscules) ; « effacer », « annuler » et « fermer » passent par une confirmation qui dit qui sera prévenu ; une perche annulée se rétablit tant que la date n'est pas passée (mot logistique) ; « fermer ma liste » = la page dit « en retrait pour l'instant », l'atelier garde tout, rouvrir à volonté ; en instance ouverte, un e-mail qui a déjà sa liste reçoit son atelier au lieu d'un doublon ; un lien d'invitation faux le dit dès l'arrivée ; l'introduction a une place fixe en tête de l'atelier, chaque action ramène à l'endroit modifié avec un mot de confirmation ; vocabulaire unifié (« quoi », « oublier mon atelier sur ce navigateur », « garder une copie de tout », courriels sans le mot « intention »).
- 2026-08-28 — Un logo : une perche tendue (trait diagonal et son point) sur un carré arrondi, couleur accent ; décliné en favicon, icône tactile et carte de partage. Sur la page publique, les perches sont des cartes (date, quoi, où, « si ça te dit → »).
- 2026-08-28 — Markdown de lettre, pas de wiki : paragraphes, listes « - », **gras**, *italique*, liens http(s) et adresses nues. Tout est échappé d'abord ; ni HTML, ni images, ni titres. Zéro dépendance (md.go, ~60 lignes).
- 2026-08-28 — Le logo est un bâton, pas un trait : courbe douce, base épaisse, bout fin, un moignon de branche (Gilles : « plus organique »). L'empreinte CSP se calcule sur le script rendu, pas sur le gabarit — html/template réécrit le JavaScript ; un test compare l'empreinte de l'en-tête au script réellement servi.
- 2026-08-28 — Seconde passe, lot A (typographie) : deux voix — ce que l'hôte écrit en Newsreader (serif), ce que l'outil affiche en Instrument Sans ; polices auto-hébergées dans `static/fonts` (136 Ko, OFL), aucune requête externe, la CSP `default-src 'self'` ne change pas. Papier moins jaune, bouton principal à l'encre, brun réservé au logo, aux liens et aux flèches ; version sombre par `prefers-color-scheme` ; focus clavier visible, cibles tactiles à 44 px.
- 2026-08-28 — Seconde passe, lot D (modèle) : une perche peut durer plusieurs jours — colonne `fin` (dernier jour), « du lundi 28 septembre au vendredi 2 octobre », journées entières dans l'ICS, présente sur la page jusqu'à son dernier jour, purge et effacement comptés depuis ce jour ; changer la fin prévient comme un changement de date. **La capacité n'existe plus** (Gilles) : colonne retirée, convention 4 retirée — un nombre de places serait déjà une manière de dire non.
- 2026-08-28 — Seconde passe, lot B (mise en page) : page publique = marque en exergue, titre, introduction, puis les perches en liste (date en colonne, titre, lieu, flèche) — plus de grille de cartes, qui supposait un volume que la page n'a pas ; la perche = une ligne de faits en gras, l'engagement en une phrase, trois choix tactiles, un bouton ; l'édition = un en-tête avec deux actions (voir la page, copier le lien), des sections étiquetées à gauche, les perches en lignes, « Nouvelle perche » repliée derrière un bouton. Toujours sans JavaScript ajouté.
- 2026-08-28 — Seconde passe, lot C (le ton, Gilles) : l'outil énonce, il ne console pas — plus de « et c'est très bien aussi », de « rien ne t'est demandé », d'italiques de réconfort ni de métaphores filées. Vocabulaire : « édition » remplace « atelier » (plus compréhensible), « lien d'édition » remplace « clé », « perche » tout court remplace « perche tendue », « Nouvelle perche » remplace « Tendre une perche », « Répondre » remplace « Déposer ma réponse », « j'aurais bien aimé » perd son « ah zut ». Le silence tient en une phrase factuelle sur la page de réponse (« Ne pas répondre est aussi une réponse. »). Courriels alignés. Ceci révise les lignes de vocabulaire du 28 août ci-dessus ; le cookie garde son nom `atelier`, les routes `/e/…` ne changent pas.
